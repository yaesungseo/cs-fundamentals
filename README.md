# CS Fundamentals
Small concepts. Strong foundations.

An English-language knowledge base for CS students who want to understand the tools, machines, and ideas behind software.

## Start here
Read one guide, explain it in your own words, and try its exercise. Basic familiarity with variables, loops, and functions is helpful; no systems background is assumed.

1. [Developer tools and Git](topics/01-developer-tools/README.md) — repositories, commits, branches, terminals, and collaboration.
2. [Computer hardware](topics/02-computer-hardware/README.md) — CPU, GPU, FPGA, memory, and storage.
3. [Programming languages](topics/03-programming-languages/README.md) — Python, Java, C, C++, JavaScript, and execution models.
4. [Operating systems](topics/04-operating-systems/README.md) — processes, threads, virtual memory, and concurrency.
5. [Networks and the web](topics/05-networks-and-web/README.md) — IP, DNS, TCP, UDP, HTTP, and HTTPS.
6. [APIs and software interfaces](topics/06-apis/README.md) — contracts, endpoints, libraries, SDKs, and REST.
7. [Databases](topics/07-databases/README.md) — keys, SQL, indexes, transactions, and data modeling.
8. [Software engineering and security](topics/08-software-engineering/README.md) — testing, debugging, dependencies, and access control.

## How this repository is organized
Each topic folder contains an introductory guide and a list of subjects to expand. These are starter notes, not a complete textbook. The [roadmap](ROADMAP.md) distinguishes existing guides from planned articles.

Use the [concept template](templates/concept.md) when adding a focused article. See [contributing guidelines](CONTRIBUTING.md) for the expected style.

## Companion repository
[CS Algorithms](https://github.com/yaesungseo/cs-algorithms) covers data structures, correctness, complexity, and implementations. This repository focuses on how computing systems and development tools work.
