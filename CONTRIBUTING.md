# Contributing
Write all documentation, examples, and comments in English.

1. Choose one focused topic from the roadmap.
2. Start with [the concept template](templates/concept.md).
3. Explain unfamiliar terms before using them.
4. Include an original example, a misconception, and a self-check exercise.
5. Cite authoritative sources for technical claims that need verification.
6. Check relative links and run any executable examples.
7. Add the article to its topic index; mark roadmap items complete only when the article exists.

Keep comparisons nuanced: avoid claims such as “compiled languages are always faster.” Separate language properties from implementation details. Do not copy textbook passages or proprietary course materials.
